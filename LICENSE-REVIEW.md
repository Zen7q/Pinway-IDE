# Перевірка ліцензування Pinway IDE

Перевірено 2026-11-24. `LICENSE` містить власну Pinway IDE Source-Available License 1.0 під узгоджені побажання автора. Текст потребує юридичної перевірки. Наведений нижче огляд є технічною перевіркою залежностей і способів інтеграції.

## Узгоджені умови

Код доступний для вивчення, модифікації та безкоштовного поширення. Дозволена оплачувана робота в IDE й продаж створених прошивок і пристроїв. Продаж копій IDE та похідних версій потребує окремого письмового дозволу. Зберігаються повідомлення про авторство, ліцензія та позначення змін.

У тексті уточнено платні пакети й підписки, добровільні пожертви та окремі послуги. Для згенерованих runtime-файлів і шаблонів надано дозвіл на комерційне поширення у складі користувацьких проєктів. Сторонні компоненти зберігають свої ліцензії. Обов'язкової публікації коду форків цей текст не вводить.

Це source-available ліцензія. Обмеження продажу суперечить критерію вільного поширення у визначенні OSI. [Open Source Definition](https://opensource.org/osd)

## Результат технічної перевірки

| Частина | Перевірено | Висновок і потрібні дії |
|---|---|---|
| JavaScript | У `package-lock.json` 58 сторонніх пакетів із MIT або Apache-2.0 OR MIT. Власний кореневий пакет не має поля license. | Дозвільні ліцензії допускають обрану модель за виконання умов. `scripts/assets.sh` збирає notices для CodeMirror та його UI-залежностей. Повноту notices конкретної поставки слід перевіряти за її складом. |
| Rust workspace | `cargo metadata --locked --filter-platform aarch64-apple-darwin --format-version 1` успішно розв'язав 386 пакетів, включно з двома власними. | Це обидва workspace members та їхні build/transitive dependencies. Список ширший за склад одного Tauri executable. Виявлено дозвільні ліцензії, MPL-2.0 та окремі ліцензії шрифтів і Unicode. Результат метаданих потребує звірки з файлами й реальною поставкою. |
| MPL-2.0 | `cssparser 0.37.0`, `cssparser-macros 0.7.1`, `dtoa-short 0.3.5`, `option-ext 0.2.0`, `selectors 0.38.0` у workspace graph. | MPL дозволяє більший твір з іншою ліцензією. Потрібно зберегти права на MPL-файли й повідомити, де доступні відповідні джерела. Визначити, які з цих пакетів входять у кожен binary. |

Потрібна перевірка точних джерел, build scripts і способу їх надання для кожного поширюваного binary. |
| Display libraries | `config/display-libraries.lock.json` фіксує 10 бібліотек. Джерела й notices пакуються окремо. | Бібліотеки входять у користувацькі прошивки, власна ліцензія Pinway їх не замінює. GPL/LGPL-вимоги конкретного драйвера можуть стосуватися поширюваної прошивки. |
| Waveshare templates | Перевірено `src-tauri/display-templates/waveshare169/THIRD_PARTY.md`. | Залишаються upstream notices Waveshare та Felix Biego. Додатковий дозвіл на output охоплює тільки права авторів Pinway. |

MPL допускає іншу ліцензію для більшого твору за збереження умов для MPL-частин. Окремі процеси зазвичай можуть мати різні ліцензії, однак характер їхнього зв'язку має значення. Для GPL binaries потрібно виконати відповідний спосіб надання Corresponding Source. [Mozilla MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/), [GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.html), [GPLv3, section 6](https://opensource.org/license/gpl-3.0)

## Що ще потрібно перевірити

- Юристу перевірити формулювання заборони продажу, платних пакетів, послуг, винятку для generated output, припинення прав і застосовного права.
- Підтвердити права на весь власний код, графіку та внески. Ліцензія не змінює раніше надані дозволи й не дає автору права одноосібно перелiцензувати чужі внески.
- Для кожної публічної binary-поставки підготувати повний перелік Rust notices, включно з MPL, Unicode й шрифтами, відповідно до фактично включених компонентів.
- Для GPL/LGPL binaries і libraries перевірити доступність точного Corresponding Source та застосовні вимоги до relinking, runtime exceptions й build scripts. Оформити повідомлення про отримання джерел поруч із завантаженням застосунку. Upstream URLs у `THIRD_PARTY.md` є довідкою, а не підтвердженням виконання всіх цих вимог.

Початкова перевірка не виявила прямого GPL-linking у власному Tauri host. Вона не встановлює повної юридичної сумісності або готовності всіх попередніх binary-збірок до публічного поширення. У цьому етапі попередні `.app` не перебудовувалися. Нове пакування додає `LICENSE` та цей огляд до Resources.
