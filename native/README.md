# Pinway Native

Нативний застосунок Rust + egui. Редактор, панелі, діалоги й системна частина компілюються в один executable.

Запуск із кореня репозиторію через `cargo run --manifest-path native/Cargo.toml`.
Комплект Arduino готується наявним `scripts/toolchain.sh`.
Для macOS `bash scripts/package-native.sh` створює підписаний ad hoc застосунок у `dist/native`.

Наразі реалізовані редактор C++ з підсвічуванням, вкладки, дерево файлів, створення файлів і папок, збереження й чернетки, новий та наявний скетч, каталог плат, улюблені, вибір USB, параметри плати, компіляція й завантаження Arduino CLI, пошук і встановлення бібліотек, Serial Monitor на 115200 і надсилання рядків, масштаб, згортання панелей.

До завершення міграції потрібно перенести автодоповнення, переходи до помилок, карти пінів, Serial Plotter, розширені налаштування Serial та всі попередні сценарії відновлення. Windows/Linux і фізичне прошивання нативної версії потребують перевірки.
