# Спільний дизайн Pinway

Етап 2026-11-22: оформлення поточного Display поширено на Code, Build, головний екран, список проєктів, налаштування, меню, бібліотеки, параметри плати, консоль, Serial Monitor, Plotter та діалоги. Нових вкладок або інструментів не додано.

`src/design-tokens.css` містить палітру Display, ролі кольорів, шрифти, радіуси й тіні для темної та світлої тем. `src/studio.css` задає спільні стани панелей, полів, кнопок, списків, діалогів і компактного компонування. Геометрія робочих просторів залишається у відповідних стилях: Code має закріплені редактор і консоль, Build — полотно та доковані панелі, Display — плаваючі панелі. Зображення компонентів, дані схем і графіка користувацьких дисплеїв мають власні кольори.

Збережено глобальні налаштування теми, акценту, масштабу й автозбереження, клавіатурні команди та native macOS chrome. Кольори сітки й підписів Plotter тепер беруться зі спільних токенів. Коротка шапка Code використовує кнопки з іконками, доступними назвами та підказками; нижня панель залишається доступною у вузькому доку.

## Перевірка

- `npm run test:display`: 15/15; `npm test`: 23/23 Rust tests.
- UI bundle та всі CSS файли проходять esbuild без попереджень синтаксису; `git diff --check` проходить.
- Native UI: головний екран, повторне відкриття Yo зі списку, Code, Build, Display, бібліотеки (11 установлених), меню робочих просторів, плати й Tools, налаштування теми, Serial Monitor, новий проєкт (скасовано), швидке відкриття файла. Світла й темна теми перевірені у застосунку. Полотно Build не редагували, прошивання не запускали.
- Перевірка native вікон 1320×820 та 830×560, масштабів 90–150% виявила й усунула обрізання Tools, нижніх вкладок і полів Serial Monitor. Макет інспектора Display не виходить горизонтально за панель.
- Ізольований UI на `tests/display-harness.cjs` з `?studio=1` використовує пам’ять замість файлів та API плати. Для 553×373 CSS px і масштабу 150% підтверджено межі редактора/панелі, видимі кнопки та поле надсилання без виходу за контейнер. Перевірені світла тема, власний фіолетовий акцент і клавіатурний фокус поля Display: суцільний контур 2 px, ширина інспектора без горизонтального переповнення.
- Контрольні суми всіх файлів прикладів, крім ігнорованих результатів компіляції, звірені з початком перевірок: змін немає. Native backend, firmware runtime та координати схем у цьому етапі не змінювалися.
