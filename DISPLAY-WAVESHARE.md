# Waveshare 1.69″ Touch LCD у новому проєкті

Підтримуваний профіль: Waveshare 1.69″ Touch LCD, 240×280, ST7789V2 + CST816, класична ESP32 Dev Module. Інші моделі ESP32 поки не мають цього готового профілю контактів.

1. Відкрий Display → Параметри полотна.
2. У «Модель дисплея» вибери Waveshare 1.69″ Touch LCD.
3. У «Налаштувати контакти» вкажи своє підключення. VCC — 3V3, GND — GND. Повторне використання контакту або несумісний GPIO блокує застосування. Можна зберегти власне підключення для наступних проєктів на цьому Mac.
4. Створи макет. Для повзунка вибери змінну Code, діапазон 0–255, активацію «Дотик» і «Без додаткової дії». Прив’язка сама записує значення повзунка у змінну. Для кнопки переходу вибери «Перейти на сторінку».
5. У Code вибери ESP32 Dev Module і натисни «Перевірити» або «Завантажити».

Pinway автоматично підготує драйвери LCD/тачу, актуальні зображення всіх сторінок, області дотику та запуск. Ручний експорт, копіювання файлів і додавання include не потрібні. Згенеровані файли зберігаються у src/pinway_display; основний .ino залишається без змін. Запуск дисплея та обслуговування тачу під час delay додаються лише до тимчасової копії для компіляції. Користувацький loop виконує власну логіку з оновленою змінною.

Якщо згенерований файл змінено вручну, Pinway зупинить збірку й покаже різницю, зберігши ручні зміни. Початковий код та налаштування Yo перед перевіркою збережено в .pinway/backups.

## Поточні межі

Підтримуються кілька сторінок, дотикові переходи, статична графіка та одна числова змінна Code з цілим діапазоном до 257 станів. Змінну можна показувати в тексті, повзунку й індикаторі; touch-повзунок змінює її. Альтернативний режим — один GPIO HIGH/LOW. Змішування кількох змінних, GPIO та довільних C++ подій ще не підтримується; несумісні дії дають явне повідомлення перед збіркою. Це не універсальний аналізатор C++.

Драйвери інших дисплеїв уже включені до пакета IDE, але автоматичне налаштування нового проєкту наразі реалізоване для цього Waveshare. Фізичне обладнання раніше перевірено на TouchLed169; новий автоматичний сценарій треба окремо перевірити на платі.
