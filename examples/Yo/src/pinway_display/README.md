# Pinway Display — Waveshare 1.69″

Ці файли створено з макета та контактів Display. Code залишається твоїм; Pinway додає виклики запуску/тачу в копію для компіляції. Звичайні delay() в головному .ino обслуговують дисплей під час очікування.

Ручні зміни захищено .pinway/display-generated.json. При конфлікті Pinway покаже різницю та зупинить збірку без перезапису. Змінюй графіку та контакти в Display.
