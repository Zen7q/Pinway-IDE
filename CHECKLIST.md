# Pinway IDE — перевірка нативної версії 0.3

- Rust + egui + wgpu збираються через Cargo. JavaScript/HTML/CSS прибрано з актуального дерева.
- П'ять тестів перевіряють створення скетчів, захист шляхів, нормалізацію й діагностику та USB-профілі.
- На фізичній ESP32-C3 скомпільовано й записано скетч FirstPinRoject із FastLED 3.10.9. esptool підтвердив хеш і перезапустив плату.
- Під час перевірки прошивання викликано той самий Rust-модуль Arduino через CLI режим --smoke. Натискання кнопки завантаження у фінальному UI ще потребує окремого проходу.
- Автодоповнення Ctrl+Space, карти пінів, Plotter й імпорт сеансу реалізовані в Rust. Розширені сценарії та Windows/Linux потребують подальшого тестування.
