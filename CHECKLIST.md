| USB до та після запуску; кілька пристроїв | Підключити один пристрій до запуску, другий після відкриття проєкту; перевірити окремі сповіщення і вибір порту | Потрібні фізичні плати |
| Від’єднання / повернення / зниклий порт | Від’єднати вибраний пристрій; статус зміниться, редагування працює; підключити й повторно вибрати порт | Потрібна фізична плата |
| Авто / чип / невідома модель / вручну | Спробувати Uno, ESP і Nano з USB-UART; звірити запропонований профіль, назву чипа, ручний вибір і повторне автовизначення | Ручний вибір профілю перевірено; авто та ідентифікація USB потребують фізичних плат |
| Відсутній або зайнятий порт, неправильний профіль або бутлоадер | Спробувати без порту; зайняти порт іншим застосунком; вибрати неправильний профіль або Nano CPU; переглянути лог, виправити, повторити | Відсутній порт правильно блокує завантаження; решта потребує фізичної плати |
| Збірка без плати | Зібрати базовий скетч для всіх чотирьох профілів | Пройдено в `.app` без зовнішньої мережі |
| Помилка .ino та відсутня бібліотека | Внести невідомий символ, звірити рядок у редакторі; додати невідомий include, перевірити повний лог | Пройдено в `.app`; рядки також збігаються для тимчасово нормалізованого скетчу |
| Менеджер бібліотек | Знайти ArduinoJson за назвою, встановити, побачити версію та зібрати скетч із бібліотекою | Пройдено в `.app`: ArduinoJson 7.4.3, збірка для ESP32 |
| Невдале та повторне завантаження | Витягти USB під час прошивання, перевірити помилку й повторити після підключення | Потрібна фізична плата |
| Serial Monitor | Відкрити на 115200, побачити Serial.println, прошити й відкрити монітор знову | Потрібна фізична плата. Псевдотермінал macOS не підтримує modem bits, які запитує Arduino monitor |
| Перший запуск .app без Arduino | Запустити з чистими каталогами Pinway та HOME, системним PATH і без зовнішньої мережі; повторити на окремому чистому Mac | Пройдено з чистим профілем на цьому Mac, де вже є Rosetta 2; окремий чистий Mac не перевірено |
| Uno R3 | Підключення → сповіщення → Uno → збірка → запис → серійний вивід | Збірка пройшла; USB, запис і запуск потребують Uno R3 |
| Nano clone | Той самий сценарій; Arduino Nano → Tools → ATmega328P (Old Bootloader) | Збірка зі старим бутлоадером пройшла; USB, запис і запуск потребують Nano |
| ESP32 | Той самий сценарій; ESP32 Dev Module | Збірка пройшла; визначення чипа, запис і запуск потребують ESP32 |
| ESP32-C3 | Той самий сценарій; ESP32C3 Dev Module; для native USB перевірити USB CDC On Boot та можливу зміну порту | Збірка пройшла; визначення чипа, запис і запуск потребують ESP32-C3 |

Фізичний тест: у `setup()` додати `Serial.begin(115200);`, у `loop()` — `Serial.println("Pinway OK"); delay(1000);`. Після успішного завантаження відкрийте Serial Monitor на 115200 бод і перевірте повторюваний рядок. Якщо плата має відомий вбудований LED, додатково перевірте блимання. Профілі та кроки для кожної плати наведено в [README](README.md#перевірка-на-платі).

## Виправлення, знайдені під час перевірки

| Відтворення | Виправлення та повторна перевірка |
|---|---|
| Підготувати комплект із локального Arduino-кешу; запустити CLI з чистими даними без мережі. Службові інструменти не знаходилися. | Копіювання створює окремий каталог виробника для `builtin/tools`. Повторно пройшли всі чотири збірки без мережі. |
| Перевірити підпис пакета після перейменування Electron Helper. | Підписано основний пакет і вкладені компоненти. `codesign --verify --deep --strict` пройшов. |
| Пошук ArduinoJson повертав бібліотеки, які згадують ArduinoJson лише в описі. | Пошук обмежено полем назви Arduino CLI; точний збіг показується першим. |
